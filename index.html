      How this page works

      1. 01

        Watch

        Every six hours, a GitHub Action reads public certificate-transparency logs for new subdomains of theojaffee.net.

      2. 02

        Read

        When a new one is live, it pulls the site’s title and description and takes a screenshot in light and dark mode.

      3. 03

        Publish

        It commits the result to projects.json, and the new plate appears here.
